## Executive Pulse — แดชบอร์ดการเข้าร่วมกิจกรรมของผู้บริหาร
ระบบบนเบราว์เซอร์สำหรับผู้บริหาร ออกแบบให้ใช้งานง่าย เปิดไฟล์ `executive-dashboard.html`
ได้ทันที (ไม่ต้องติดตั้ง) ข้อมูลฝังอยู่ในไฟล์ สรุปจากแบบสำรวจผู้บริหารเข้าร่วมกิจกรรมประจำสัปดาห์
(6 สัปดาห์ · 24 กิจกรรม · ผู้บริหาร 10 ท่าน)

### โครงสร้างสิทธิ์การเข้าถึง
ระบบแบ่งเป็น 2 ส่วนชัดเจน:

| ส่วน | ต้องเข้าสู่ระบบ | ประกอบด้วย |
|------|----------------|------------|
| **หน้าสาธารณะ** | ไม่ต้อง | **รายงานรายสัปดาห์** — ใครมีลิงก์ก็เปิดดูได้ทันที |
| **ผู้ดูแลระบบ** | ต้อง | ภาพรวมผู้บริหาร · ตารางสถานะรวม · รายบุคคล & อันดับ · สร้างแบบสำรวจ · จัดการรายชื่อ · จัดการผู้ใช้ · ช่วยเหลือ · พิมพ์/ส่งออก |

บัญชีเริ่มต้นคือ `admin` / `admin1234` — **ควรเปลี่ยนหรือเพิ่มผู้ใช้ใหม่แล้วลบบัญชีเริ่มต้นทิ้งก่อนใช้งานจริง**
(เมนู “จัดการผู้ใช้ระบบ”) รหัสผ่านถูกเก็บแบบ hash (SHA-256) และ session อยู่แค่ในแท็บนั้น

> **ข้อจำกัดสำคัญ:** แอปนี้ทำงานฝั่งเบราว์เซอร์ล้วน การกันสิทธิ์จึงเป็นระดับ UI เท่านั้น
> ใช้กันผู้เข้าชมทั่วไปไม่ให้กดแก้ข้อมูลโดยไม่ตั้งใจได้ แต่**ไม่ใช่ระบบยืนยันตัวตนฝั่งเซิร์ฟเวอร์**
> ผู้ที่เปิด DevTools เป็นสามารถข้ามได้ หากต้องการความปลอดภัยจริงต้องเพิ่ม auth ที่ Cloudflare Worker

### มุมมองและความสามารถ
- **รายงานรายสัปดาห์ (สาธารณะ)** — แบนเนอร์สรุปอัตราเข้าร่วมสัปดาห์ล่าสุด เลือกสัปดาห์ ดูรายละเอียด
  กิจกรรม วัน–เวลา–สถานที่ และผู้เข้าร่วมรายคน
- **ภาพรวมผู้บริหาร** — KPI การ์ด, การ์ด “สัปดาห์นี้” (ลัดไปหน้ารายสัปดาห์), แนวโน้มอัตราเข้าร่วม,
  สัดส่วนสถานะ, อันดับรายบุคคล และไฮไลต์อัตโนมัติ
- **ตารางสถานะรวม** — เมทริกซ์ฮีตแมป ผู้บริหาร × กิจกรรม เห็นทุกอย่างในหน้าจอเดียว
- **รายบุคคล & อันดับ** — จัดอันดับการเข้าร่วม พร้อมประวัติรายกิจกรรมของผู้บริหารแต่ละท่าน
- **สร้างแบบสำรวจ** — กด “สร้างฟอร์มอัตโนมัติ” เพื่อเติมรายชื่อผู้บริหารให้พร้อมติ๊ก เข้าร่วม/ไม่เข้าร่วม
  แล้วบันทึกเข้าแดชบอร์ด (เก็บในเบราว์เซอร์ ผลรวมอัปเดตทุกหน้า), ส่งออก JSON/CSV หรือพิมพ์แบบฟอร์ม
  - **ลิงก์ให้ตอบ + กำหนดปิดรับ (deadline)** — สร้างลิงก์แชร์ (LINE/อีเมล) ผู้บริหารเปิดลิงก์ เลือกชื่อตนเอง
    และติ๊กการเข้าร่วม ระบบ**ปิดรับอัตโนมัติเมื่อถึงกำหนด** (แสดงหน้า “ปิดรับคำตอบแล้ว”)
    · โหมดออนไลน์ = ลิงก์สั้น คำตอบเข้าระบบทันที · โหมดออฟไลน์ = ข้อมูลฝังในลิงก์ (URL hash) ไม่ต้องมีเซิร์ฟเวอร์
  - **แก้ไขแบบสำรวจ** — เปิดแบบสำรวจที่บันทึกไว้กลับมาแก้ แล้วบันทึกทับรายการเดิม (ไม่สร้างรายการซ้ำ)
  - **ดูผลสด / นำเข้าคำตอบ** — ดูผลแบบเรียลไทม์ หรือดึงคำตอบเข้าแดชบอร์ดหลัก
    (โหมดออฟไลน์ใช้วิธีวาง “รหัสคำตอบ” ที่ผู้ตอบส่งกลับ)
  - **นำเข้า Excel/CSV แบบเลือกกิจกรรมได้** — อัปโหลดไฟล์แล้ว**ติ๊กเลือกเฉพาะกิจกรรมที่ต้องการ**
    ไม่บังคับนำเข้าทั้งไฟล์ · คอลัมน์ “ชื่อ/ตำแหน่ง” ใช้เพิ่มหรืออัปเดตรายชื่อผู้บริหารได้ด้วย
  - **จัดการรายชื่อผู้บริหาร** — เพิ่ม/แก้ไข/ลบรายชื่อและตำแหน่งได้โดยตรงในระบบ ไม่ต้องใช้ไฟล์
    (ค่าที่แก้จะถูกจำไว้ในเบราว์เซอร์ และติดไปกับแบบสำรวจที่เผยแพร่)
  - **จัดการผู้ใช้ระบบ** — เพิ่มบัญชีผู้ดูแลที่จัดการแบบสำรวจ/กิจกรรม/รายชื่อได้
- **ช่วยเหลือ & คู่มือ** — สถานะระบบแบบเด่นชัด (พร้อมใช้งาน/ออฟไลน์ พร้อมปุ่มตรวจสอบทันที),
  คู่มือการใช้งาน (SOP) เป็นขั้นตอน 1–6 สำหรับสร้างแบบสำรวจ และคำแนะนำแก้ไขปัญหาที่พบบ่อย

รองรับโหมดมืด, ปรับขนาดหน้าจอ (มือถือ/แท็บเล็ต/เดสก์ท็อป), พิมพ์/บันทึก PDF และส่งออก CSV
อัปเดตข้อมูลตั้งต้นได้โดยแก้ JSON ในแท็ก `<script id="data">` ภายในไฟล์ ส่วนแบบสำรวจที่สร้างใหม่
จะถูกเก็บไว้ในเบราว์เซอร์ (localStorage)

> **หมายเหตุ:** ข้อมูลใน localStorage แยกกันตามโดเมน — แบบสำรวจ รายชื่อ และบัญชีผู้ใช้ที่ตั้งบน
> GitHub Pages จะไม่ปรากฏบน Cloudflare Pages และกลับกัน

## Budget Pulse — วิเคราะห์ประมาณการรายรับงบประมาณเงินรายได้
แดชบอร์ดบนเบราว์เซอร์ไฟล์เดียว เปิด `budget-analysis.html` ได้ทันที (ไม่ต้องติดตั้ง) วิเคราะห์
**ประมาณการรายรับงบประมาณเงินรายได้ ภาคปกติ ปีงบประมาณ พ.ศ. 2570** (ข้อมูลรับจริง ณ 9 มิ.ย. 69)
ครอบคลุม 8 คณะ · 92 สาขาวิชา · นักศึกษาคงอยู่ 15,407 คน · รายรับรวม 341.36 ล้านบาท ใน 5 มุมมอง:

- **ภาพรวม** — KPI การ์ด (นักศึกษา, รายรับ, คงเหลือสุทธิ, การเติบโต), กราฟรายรับรายคณะ,
  โครงสร้างการจัดสรร (คงเหลือ / 20% ตามระเบียบ / 5% กองทุน), เปรียบเทียบปี 2569→2570 และไฮไลต์อัตโนมัติ
- **รายคณะ** — ตารางแผนการรับเทียบรับจริง อัตราการรับ รายรับ ยอดหักตามระเบียบ และคงเหลือ พร้อมสัดส่วน
- **รายสาขาวิชา** — จัดอันดับ 92 สาขาวิชาตามรายรับ/คงเหลือ กรองตามคณะ ค้นหา และเรียงลำดับได้ทุกคอลัมน์
- **แผน vs รับจริง** — วิเคราะห์อัตราการรับจริงเทียบแผน (นักศึกษาปี 1) และส่วนต่างรายรับรายคณะ
- **รายงานผู้บริหาร** — บทสรุปสำหรับผู้บริหาร ข้อสังเกต/ข้อเสนอแนะ และหมายเหตุระเบียบวิธีการคำนวณ (พิมพ์ได้)

รองรับโหมดมืด, ปรับขนาดหน้าจอ, พิมพ์/บันทึก PDF (ทุกมุมมองในครั้งเดียว) และส่งออก CSV
ข้อมูลฝังในไฟล์ที่แท็ก `<script id="data">` — อัปเดตได้โดยแก้ JSON ในแท็กนั้น
รายรับคำนวณจากค่าบำรุงการศึกษา (2 ภาคเรียน) + ค่าธรรมเนียมแรกเข้า หัก 5% เข้ากองทุน และ 20% ตามระเบียบวิธีงบประมาณ

## DocIntel — Document Intelligence Platform
ต้นแบบ frontend ใช้งานได้ทันที (เปิด `docintel.html`) ครอบคลุม: Dashboard, คลังเอกสาร,
ค้นหาขั้นสูง, Document Viewer, เปรียบเทียบเอกสาร, AI Analyzer, AI Chat, Knowledge Graph, Report Center

### เชื่อม Backend จริง
ดูวิธี deploy และเชื่อมต่อ API ที่ [`backend/README.md`](backend/README.md)
- ฐานข้อมูล D1 `psru-docintel` (สร้าง + ใส่ข้อมูลตัวอย่างแล้ว)
- REST API: เอกสาร CRUD + ค้นหาเต็มข้อความภาษาไทย (FTS5 trigram)
- ตั้งค่า `API_BASE` ใน `docintel.html` ให้ชี้ไปยัง Worker เพื่อใช้ข้อมูลจริง
